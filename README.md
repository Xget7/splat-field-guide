# Splat Field Guide

A maintenance guide for real equipment that runs on a phone with no network.
It shows a photoreal Gaussian-splat capture of the equipment, highlights any part you touch, walks you through procedures step by step with the right parts highlighted, and answers spoken questions through an on-device AI instructor.

Status: design.
Nothing is built yet; start with the [design](docs/specs/2026-09-29-field-guide-design.md).

## Read in this order

1. [Design](docs/specs/2026-09-29-field-guide-design.md): what it does, how it is split, how it is verified.
2. [Decisions](docs/adr/): each choice with its pros and cons, one short page each.
3. [Vocabulary](CONTEXT.md): the words the code and docs use.
4. [Research](docs/research/): the evidence behind the decisions.
