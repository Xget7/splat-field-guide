Both platforms now ship ExecuTorch 0.11.0 with the XNNPACK backend, Phonemis, React Native Audio API 1.0.0, blob-util and device-info.
Their licenses and retained native dependency notices are included in the bundled text and [source records](packages/react-native-on-device/LICENSES/ExecuTorch).
Optional offline preparation downloads Whisper Base English, Kokoro with `af_heart`, FSMN VAD and Qwen2.5 1.5B Instruct exports under Apache-2.0.
Each model URL, byte count and SHA-256 is recorded in [modelAssets.json](packages/react-native-on-device/src/local/modelAssets.json).
Phonemis uses its lexicon and neural phonemizer; the optional Brown Corpus tagger is excluded.
The superseded ONNX, FluidAudio and BART/CoreML resources are no longer bundled; their original source/license records remain retained.

## Opt-in local KUKA documentation

Private local demo builds may copy the existing KUKA source PDFs through `FIELD_GUIDE_DOCUMENTS_DIR`, only when `miris-pilot/1` is explicitly selected.
The retained [document catalog](apps/field-guide/assets/documents/catalog.json) binds each original filename, document edition, issue date, page count and SHA-256 to the source file in `splat-tools/data/reference/kuka`.
The build verifies these digests before copying, and the native viewer verifies each bundled PDF before opening it offline.
No PDF bytes are committed to this repository, and normal builds do not bundle these documents.
The operating instructions are copyright 2012 KUKA Roboter GmbH; the assembly instructions are copyright 2024 KUKA Deutschland GmbH.
Both original documents retain their page-two notice requiring express KUKA permission for reproduction or disclosure to third parties.
The copied resources include a `documents/NOTICE.txt` retaining these restrictions; local demo inclusion does not establish redistribution rights or certify applicability to the installed equipment.

The optional complete-text index retains those same source identities, editions, PDF pages and copyright notices.
It is generated outside the mobile repository and bundled only with explicit private source inclusion; no extracted manual text is committed to git.
The owner's requested online access uses client tools over the same installed corpus by default, while optional external text indexing remains subject to the original disclosure restrictions.
